Editorial Text Wrap

Typography and layout have always been intertwined. Grid and flexbox handle page layout, but neither can bend inline content around a shape the way a floated element with shape-outside can. This paragraph wraps around the circular image to the left because shape-outside: circle(50%) tells the browser to treat the float area as a circle instead of a rectangle, while clip-path keeps the image itself clipped to match. Resize this window below 500px and the float drops away entirely, stacking the image above the text so the wrap never collapses into single-word lines on a narrow screen.
